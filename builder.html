Builder

Turn a dataset into a decision-ready deliverable.

Builder helps you move from source data to analysis, a visual canvas, and an export or presentation handoff—without starting the story from scratch each time.

Released on Apple and Android platforms

Download Clickt See the workflow

What Builder does

A practical workspace between raw information and a clear answer.

Builder is made for work that needs a little more structure than a spreadsheet view, but still needs a deliverable that a person can inspect, edit, and share.

01

Start with a dataset

Import a CSV, TSV, plain-text, or JSON file, or register a dataset manually, then choose the one you want to analyse.

02

Prepare the analysis

Work through dataset columns and analysis steps, then choose from 12 chart types—bar, line, scatter, area, histogram, box plot, heatmap, pie, donut, and more—to make the signal in the data easier to inspect.

03

Build a usable canvas

Arrange visual analysis and supporting content into a deliverable that can be reviewed before it is shared.

04

Export or continue the story

Builder’s current canvas export options are PNG, DOC, and PPT, and a Builder page can be sent into Presentation.

A familiar Friday afternoon

The spreadsheet you used to dread building.

Before Builder

Sales numbers come in from a handful of different sources as separate exports. Someone spends an hour combining them by hand, building pivot tables, and reformatting charts before they even look right—every single week, from scratch.

With Builder

Import the same exports, and Builder works through the columns and builds the chart with you on a canvas you can adjust. What used to be an hour of manual spreadsheet work becomes a few minutes of review—and it is ready to hand off to Presentation without rebuilding anything.

A deliberate path from source to shareable work.

The point is not to automate a conclusion. It is to prepare a readable analysis and preserve the judgment needed before it becomes an output.

  1. 1

    Bring in the dataset

    Import the data you want to work with or create a dataset manually inside Builder.

  2. 2

    Choose the analysis

    Select the relevant dataset details and shape the analysis steps or chart treatment around the question.

  3. 3

    Make the deliverable

    Arrange the result on the Builder canvas so it can be reviewed as a coherent, readable output.

  4. 4

    Export or hand off

    Export the canvas as PNG, DOC, or PPT, or send it to a new or existing Presentation deck.
